# Uriel Jaloto

Backend developer working on a high-volume telecom system (dialer / contact center) at Argus. Information Systems student at UFSC, Florianópolis.

I write REST APIs in **Delphi** at work and build my side projects in **Go**, with a focus on SQL performance, concurrency and clean architecture.

**Stack:** Go · Delphi (DMVC Framework) · MySQL · PostgreSQL · REST · JWT · Swagger · Docker · Git

## Projects

**[surgical-rar-recovery](https://github.com/UrielJaloto/surgical-rar-recovery)** · Go · work in progress  
Recovers the password of a RAR5 archive you own when you remember part of it. Parses RAR5 binary headers directly to get the PBKDF2 parameters and spreads the work across all CPU cores with goroutines. Standard library only.

**[music-genre-fetcher](https://github.com/UrielJaloto/music-genre-fetcher)** · Go  
CLI that fills missing genres in a local music library using the Last.fm API, with a concurrent worker pool, retry with backoff and JSON/CSV/TXT export.
